# QUPPA QR Menu — Yayın Öncesi Kontrol Listesi

## Görsel kontrol

- [ ] Header ekrana sabit ve düzgün görünüyor.
- [ ] Arama butonu mobilde taşmıyor.
- [ ] Kategori ve filtre satırları yatay kayıyor.
- [ ] Ürün kartları 360px ekranda taşmıyor.
- [ ] Sepet alt barı boşken gereksiz yer kaplamıyor.
- [ ] Sipariş özeti uzun listede okunabilir.
- [ ] Ürün detay modalı iOS/Android'de düzgün açılıyor.

## Fonksiyon kontrol

- [ ] Ürün sepete ekleniyor.
- [ ] Adet artır/azalt çalışıyor.
- [ ] Liste temizleme çalışıyor.
- [ ] Favori ekleme çalışıyor.
- [ ] Dil değişimi ürün açıklamalarını da değiştiriyor.
- [ ] Live modda tema seçici gizli.
- [ ] Demo modda tema seçici açık.

## PWA / Offline

- [ ] Local server veya GitHub Pages üzerinden açıldı.
- [ ] Service Worker register oldu.
- [ ] Sayfa bir kez açıldıktan sonra offline modda tekrar açılıyor.
- [ ] Görseller yüklenmezse fallback bozuk görünmüyor.
- [ ] Versiyon değişince yeni CSS/JS geliyor.

## Satış demosu

- [ ] Bugünün önerisi doğru görünüyor.
- [ ] Öne çıkan ürünler görünüyor.
- [ ] Kahve ekleyince tatlı upsell kartı çıkıyor.
- [ ] “Şimdilik kalsın” sonrası upsell tekrar çıkmıyor.
- [ ] Garsona göster listesi fotoğrafsız ve sade.
